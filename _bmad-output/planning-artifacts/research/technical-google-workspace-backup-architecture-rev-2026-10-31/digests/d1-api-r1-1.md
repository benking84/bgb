## Leads worth chasing

1. Gmail pre-May-2026 quota values versus new values: confirm verbatim (250 units/user/sec vs 6,000 units/min/user, and messages.get raw = 60 vs older 5). This changes Gmail throughput sizing by roughly an order of magnitude.
2. Drive "charges later in 2026": the 1 TB/day/project egress and 400M units/day thresholds become billable. A TB-scale initial backup will exceed 1 TB/day. Watch for the 90-day notice on Workspace Updates / Drive release notes.
3. Whether files.download (async Operation) removes the 10 MB export ceiling for large Docs/Sheets/Slides; whether exportLinks still work for large docs with DWD credentials.
4. Changes API reference (changes.list, getStartPageToken): driveId, includeItemsFromAllDrives, and token expiry. For shared drives, decide between impersonating one member per drive vs an admin with useDomainAdminAccess.
5. Keep API OAuth scopes (keep, keep.readonly) and attachment download endpoint (media.download) details.
6. Chat: messages.list per user via DWD sees only spaces the user is a member of; DMs and space dedup strategy. Check if Vault export covers Chat for a better path.
7. Calendar API (events.list syncToken, 410 GONE on expiry) and Groups (Admin SDK Directory + Groups Settings; group conversations via Vault only) were not researched this run.
8. Workload Identity Federation / signJwt (IAM Credentials) as keyless DWD path given key creation is blocked by default.
9. Gmail raw maximum message size (Gmail limit of 25 MB send / 50 MB receive) as returned by format=raw.

## Looked for and could not find

- A fixed documented validity window for Gmail startHistoryId (Google only says "typically at least one week").
- Drive changes page token expiry.
- A documented per-user Drive download quota (none published; only per-minute units and the project egress threshold).
- Explicit statement that Forms, Sites, Jamboard, Maps or shortcuts are not exportable (they are simply absent from the export table).
- A Google primary source on New Google Sites API availability.
- Any 2025 or 2026 Google announcement deprecating or restricting domain-wide delegation itself.
- Admin-level (useAdminAccess) read access to Chat message content.
- Calendar, Groups and Gmail raw size limits: not researched within budget.
